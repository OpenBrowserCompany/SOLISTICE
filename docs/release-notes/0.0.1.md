## New

- **Solstice by The Open Browser Company.** The browser now carries its own identity: a new name, a silver emblem, a deep-space theme and rebranded app icons on every platform.
- **A Web with freedom.** The new tagline runs through the app, the website and the documentation.
- **The same browser underneath.** Chromium, Helium's privacy patches, the sidebar, WebKit engine choice, plugins and all existing features are unchanged.
- **Open-source licensing is unchanged.** Source files remain Apache-2.0; the distributed app remains GPL-3.0 because of the engine patches. The upstream copyright and corresponding-source links are preserved.

## Fixed

- Rebranded Windows, Linux, macOS, phone and website icons, plus favicons, press kit and social preview.
- The onboarding intro and Windows intro music now use the Solstice wordmark and its timing.
- GitHub Actions Linux jobs now use the Namespace runner profile `namespace-profile-solistice-browser`.
